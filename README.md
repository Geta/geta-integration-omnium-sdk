## How to build a new version?

Go to [Team City project](https://tc.geta.no/project/GetaPackages_IntegrationOmniumSDK?hideTestsFromDependencies=false&hideProblemsFromDependencies=false&branch=master&mode=builds#1119346) anmd choose branch to build from:

* `develop` - builds client against Omnium test environment ([apitest.omnium.no](apitest.omnium.no)).
* `master` - builds client against Omnium production environment ([api.omnium.no](api.omnium.no)).
